## 8. Glossário Essencial

### API

Interface pela qual um sistema envia dados e recebe respostas de outro sistema.

### Baseline

Solução simples usada como referência mínima.

Neste projeto, o baseline foi uma regra de persistência:

- se o estudante já estava em defasagem no ano atual, prever risco no ano seguinte

Ele serve para verificar se os modelos mais sofisticados realmente entregam ganho em relação a uma regra simples de negócio.

### Brier Score

Métrica que mede a confiabilidade das probabilidades previstas.

### Drift

Mudança relevante no comportamento dos dados ao longo do tempo.

### Feature

Variável de entrada usada pelo modelo.

### F2-score

Métrica que combina `Recall` e `Precision`, dando mais peso ao `Recall`.

### Ingestão

Processo de receber, validar, normalizar e persistir dados.

### Leakage

Vazamento de informação. Ocorre quando o modelo recebe pistas indevidas da resposta.

### Modelo

Método matemático que aprende padrões a partir de dados históricos.

### Precision

Proporção dos alertas emitidos pelo modelo que realmente estavam corretos.

### PR-AUC

Resumo da capacidade de separação entre classes com foco maior na classe positiva.

### Recall

Proporção dos casos positivos reais que o modelo conseguiu encontrar.

### Schema

Estrutura esperada de colunas e tipos de um arquivo.

### Schema Canônico

Formato interno único adotado pela solução para tratar todos os layouts de entrada.

### Target

Variável que o modelo tenta prever.
